## What is this?

A curated, searchable, and frankly *beautiful* library of AI prompts that actually deliver results. Every prompt has been hand-crafted and battle-tested — not generated by an AI churning out generic templates. Whether you're building a full-stack app, crafting a professional resume, designing a cloud architecture, or writing a killer investor pitch, there's a prompt here that cuts your work from hours to seconds.

**No fluff. No filler. Just prompts that work.**

## Quick Start

```bash
# Clone the repo
git clone https://github.com/JamesCowx/promptshub.git
cd promptshub

# Open in browser — that's it. No build step, no npm install.
open index.html
```

Want to add your own prompts? Edit `js/data.js` or `js/data-new.js` — just add objects to the array following the existing format:

```js
{
  id: "my-01",
  category: "web-development",
  icon: "&#x1F310;",
  title: "Your Prompt Title",
  description: "One-sentence description of what this prompt builds.",
  prompt: `The full prompt text goes here.
Multi-line prompts use template literals with backticks.
Escape any internal backticks with a backslash: \`\`\``,
  tags: ["tag1", "tag2", "keyword"]
}
```

## Design Philosophy

> "Doesn't look like AI built it."

Every pixel was chosen intentionally. The warm gold-and-midnight palette, the Playfair Display serif headings against Inter body text, the floating gradient orbs that drift at different speeds, the subtle film-grain noise texture, the 3D card tilt that follows your cursor, the staggered entrance animations, and the category-specific color accents — these aren't defaults. They're decisions.

This site is built to prove that a static HTML page with vanilla CSS and JS can feel more premium than any React framework boilerplate.
